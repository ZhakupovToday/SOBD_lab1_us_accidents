# Лабораторная работа № 1. Разведочный анализ больших данных

**Студент:** Жакупов Марат Сергеевич, группа ЭВМ-2.2
**Дисциплина:** Системы обработки больших данных

**Датасет:** [US Accidents (2016–2023)](https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents) —
7 728 394 записи о ДТП в 49 штатах США, 46 полей, CSV ≈ 3 ГБ.

**Инструменты:** HDFS, YARN, Apache Spark 3.5.2 (PySpark), Apache Iceberg 1.6.0.

## Состав репозитория
| Файл | Содержание |
|---|---|
| `1_data_preparation.ipynb` | Чтение CSV из HDFS, преобразование типов с контролем ошибок, производные признаки, сохранение в Iceberg |
| `2_exploratory_analysis.ipynb` | Пропуски, дубликаты, статистики и выбросы, категориальные признаки, распределения, время, корреляции |
| `Zhakupov_SOBD_kursovaya.docx` | Пояснительная записка (глава курсовой работы) |

## Основные результаты
- Исходные данные: 7 728 394 записи; итоговая очищенная выборка: 7 578 362 записи (исключено 1,94 %).
- Пропуски структурные: зависят от источника данных и года.
- Удалено 117 725 дубликатов (одно событие под разными `id`) и 32 307 записей с нереалистичной длительностью или протяжённостью.
- 79,4 % ДТП имеют тяжесть 2; пики числа ДТП — будни, 7–8 и 15–17 часов.
- Сильных линейных связей между числовыми признаками не выявлено.
